các câu lệnh tìm kiếm whereis - which

whereis
cú pháp: whereis [tùy chọn] tên_lệnh
chức năng:
	- tìm kiếm vị trí của các file liên quan đến một lệnh (như file thục thi, file mã nguồn, trang man)
	- hiểm thị đường dẫn đến các file được tìm thấy
tùy chọn:
	-b: chỉ tìm file thực thi
	-m: chỉ  tìm file mã nguồn
	-s: chỉ tìm trang man
	-u: tìm kiếm trong thư mục do người dùng cài đặt


which
cú pháp: which [tùy chọn] tên_lệnh
chức năng:
	- tìm kiếm vị trí của file thực thi của một lệnh
	- hiểm thị đường dẫn dến file thực thi được tìm thấy
tùy chọn:
	-a: hiểm thị tất cả các file thực thi được tìm thấy
	-n: không hiểm thị đường dẫn
	-p: hiểm thị thông tin chi tiết về file thực thi
