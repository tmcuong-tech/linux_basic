cấu hình địa chỉ ip

cấu hình bằng lệnh
- cấu trúc lệnh
	ifconfig <tên_card_mang> <ip> netmask <netmask> up

lưu ý: 
- việc cấu hình địa chỉ IP tĩnh bằng ifconfig chỉ có hiệu lực tạm thời và sẽ bị mất sau khi khởi động lại hệ thống.
- để cấu hình vĩnh viễn, cần phải sửa file cấu hình hệ thống tương ứng, chẳng hạn như /etc/netplan/

ví dụ:
	sudo ifconfig eth0 192.168.1.100 netmask 255.255.255.0

sudo ip addr add <địa chỉ IP>/<subnet mask> dev <tên_card_mạng>
sudo ip link set dev <tên_card_mạng> up

cấu hình địa chỉ ip vĩnh viễn
sudo apt install netplan.io - chứa các file để chỉnh cấu hình card mạng

ví dụ file cấu hính
sudo nano *.yaml - lệnh vào file cấu hình

cấu trúc của cấu hình mạng trong file *.yaml
	network:
	  version: 2
	  renderer: networkd
	  ethernets:
	     eth0:
	     	addresses: [192.168.1.100/24]
		gateway4: 192.168.1.1
		nameservers:
		   addresses: [8.8.8.8, 8.8.4.4]
